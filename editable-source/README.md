# Shonil Dabreo Portfolio

An editorial, recruiter-friendly portfolio for data engineering, analytics, software and decision-focused work.

[![GitHub profile views](https://komarev.com/ghpvc/?username=shonil24&label=Profile+views&color=48c7c6&style=flat-square)](https://github.com/shonil24)

## Purpose

This site is designed to make the work easy to scan and easy to trust:

- The home page explains the point of view and includes an interactive workbench.
- Projects show the problem, approach, trade-offs and outcome.
- Experience keeps dates, roles and measurable impact aligned.
- Field notes provide a lightweight publishing workflow.
- The entire site is static, free to host, and easy to edit in VS Code.

## View counts

The README now includes a free GitHub profile-view badge for [`shonil24`](https://github.com/shonil24). That badge measures visits to the GitHub profile, not visits to this portfolio website.

| Surface           | Status                                                     | Where to see the count                      |
| ----------------- | ---------------------------------------------------------- | ------------------------------------------- |
| GitHub profile    | Badge added                                                | The badge above / Komarev dashboard         |
| Portfolio website | GoatCounter integration ready; endpoint not configured yet | Your free GoatCounter dashboard after setup |
| GitHub repository | GitHub-owned metric                                        | GitHub → repository → Insights → Traffic    |

GitHub Pages does not provide a built-in website visitor counter. The portfolio includes an opt-in GoatCounter script for this purpose. Follow [`SETUP.md`](./SETUP.md#track-portfolio-website-views) to activate it after creating a free GoatCounter site.

The static source does not fabricate a global count. It only reports data after a real analytics endpoint has been connected.
