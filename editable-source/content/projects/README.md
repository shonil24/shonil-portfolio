# Project story files

Every project in the archive has one Markdown file here. The file controls the project card, detail page, tags, impact line, and the four deeper story sections.

Frontmatter uses `|` between multiple tags or categories:

```yaml
tags: Python|Pandas|SQL
categories: data|analytics
featured: false
```

To add a project, copy any existing project file, update the frontmatter, add the four sections, and refresh the app.
