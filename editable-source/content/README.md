# Portfolio content

This folder is the editable content layer for the portfolio. Each project and blog post is a small Markdown file with frontmatter at the top. Edit the text, save, and rebuild or restart the preview.

## Quick workflow

1. Copy an existing file in `projects/` or `blog/`.
2. Change the frontmatter values and the Markdown sections.
3. Use a unique `id` made from lowercase words and hyphens.
4. Run the site locally with the existing portfolio workflow.
5. Build and publish the updated static site.

Projects use `Why this mattered`, `Approach`, `Trade-offs and reasoning`, and `Outcome` sections. Blog posts use one `Post` section split into paragraphs.
